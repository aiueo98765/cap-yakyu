# キャップ野球

ペットボトルのキャップを指ではじいて投げ、プラスチックバットで打ち返す 3D キャップ野球。
体育館の勝ち抜き大会と、**別のスマホの人とのオンライン対戦**が遊べます。

遊ぶ → https://aiueo98765.github.io/cap-yakyu/

## 中身

`index.html` 1枚で動きます（three.js は CDN、人の形は末尾に埋めこんだ glTF、音はその場で合成）。

| ファイル | なに |
| --- | --- |
| `index.html` | 本体。これだけサーバーに置けば動く |
| `index.orig.html` | 作りかえる前の控え。ビルドの土台 |
| `card.png` | SNS に貼ったときの画像 |
| `nettest.html` | 通信の速さをはかる確認用ページ |
| `build/` | `index.orig.html` に差分をあてて `index.html` を作る道具 |

## 作りかえかた

`index.html` を直接いじると 次のビルドで消えます。直すのは `build/` の中。

```
python build/build.py
```

`index.orig.html` + `build/*.css|html|js` + `build/patch.py` → `index.html`。
あてる所が見つからなければ その場で止まります（静かに壊さないため）。

## オンライン対戦

2段がまえでつなぎます。

1. **直つなぎ（WebRTC）** — ふだんはこちら。相手のスマホと直につながるので 行き帰り 30〜80ミリ秒
2. **中継（Firestore）** — 直つなぎができない回線のときの保険。行き帰り 300〜600ミリ秒

部屋さがしと、直つなぎのための合図は Firestore でやります。
打った結果は**打つ人のスマホが決める**ので、通信が少し遅れても 打つタイミングはずれません。

確認用のつけ足し（URL のうしろに付ける）

| | |
| --- | --- |
| `?mocknet` | 同じブラウザの別タブどうしでつなぐ |
| `&lag=200` | 合図の遅れをまねる（ミリ秒） |
| `&relay` | 直つなぎを使わず 中継だけ試す |
| `?room=1234` | その番号の部屋に入る画面から始める |
